# iOS analytics privacy release checklist

Source behavior: `src/analytics/mobileConsent.ts` requires both this device's explicit choice and `PUT /api/analytics/consent` success before optional events leave the app. The first-run choice is `src/analytics/PrivacyChoice.tsx`; Settings > Privacy can withdraw it. Declining does not affect app use. A pending in-memory queue holds at most 32 allowlisted events for 24 hours and is erased on decline, account switch, or process exit. It contains no prompt or project content. Release requires the server to enforce the choice and erase retained identifiable events on withdrawal.

The iOS privacy manifest declares Product Interaction, Other Usage Data, and Coarse Location for Analytics, conservatively marked Linked to User because people may separately opt into account linkage. Tracking is false. No IDFA, device fingerprint, GPS permission, advertising attribution, or cross-company tracking is part of this feature. App Store Connect privacy answers need the same three categories, Analytics purpose, linked-to-user possibility, and no cross-company tracking. They must also cover all other app features and bundled SDKs; the privacy policy URL is required and a privacy choices URL is optional. **App Store Connect answers have not yet been updated for this candidate.** Apple documents the [data types](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacycollecteddatatypes/nsprivacycollecteddatatype), [Analytics purpose](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacycollecteddatatypes/nsprivacycollecteddatatypepurposes), and [App Store Connect privacy update flow](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-app-privacy).

Release gate: publish the matching privacy notice (purpose, optional choice, country from IP, account-link choice, retention, withdrawal/deletion) before enabling collection; verify decline/accept/withdraw on a native install and real production consent endpoint; regenerate Xcode's privacy report and update App Store Connect answers. A local source build or browser fixture is not an App Store release.
