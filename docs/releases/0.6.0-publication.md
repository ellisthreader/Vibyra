## Publication proof

- Windows NSIS, AppImage and Debian public downloads reproduce all signed CI hashes and sizes; see `0.6.0-artifacts.json`.
- All 27 feed checks passed: seven older versions offered 0.6.0, while 0.6.0 and a future version received 204, on each of the three supported routes.
- An isolated normally mounted 0.5.0 AppImage downloaded 0.6.0, replaced its package and relaunched into the matching new native binary.
- The stable local launcher file now matches the published 0.6.0 AppImage. The pre-existing user workspace was not restarted; it loads the new version on a normal restart.
- Live backend billing/model routing and new release-copy source hashes match the exact-source deployment archive.

## Validation and limits

- Desktop: 774 frontend tests and native format/Clippy/tests/build passed. Signed Windows install/launch, AppImage launch and Debian install/launch passed CI.
- Packaged native permission bridge: Codex and Claude each completed the disposable code task, passed an unchanged test, persisted results and prevented an explicitly denied file write. These ran on Linux with the signed-in default provider accounts; they do not certify every provider/account/OS configuration.
- Backend: 396 tests with no assertion failures; one pre-existing skip. Four PHPUnit mock notices introduced by the dependency update were fixed with stubs and the focused test class passed. No database migration changes.
- Phone: 28 focused tests, typecheck, exports, all four compact/large light/dark hosted UI journeys, terminal isolation and real UI-to-Host execution/reconnect/files/control passed.
- iOS simulator: [successful EAS build](https://expo.dev/accounts/xellis/projects/vibyra/builds/ad13d7ae-b896-40d1-bcd7-b5c3b9dca73b). This is not a signed physical-iPhone or TestFlight release; Apple distribution credentials are not configured.
- Host: both OS package jobs passed Rust format, Clippy, tests and CLI launch; downloaded hashes and signatures were independently verified. Unix-specific terminal integration tests do not establish the corresponding physical Windows behavior.
- Dependency audits: no high/critical npm findings. Root/mobile retain moderate transitive Expo/uuid advisories; the offered automated fix would downgrade to incompatible Expo 46.
- Security CI backend/mobile/repository policy/SBOM jobs passed. The full-history secret scan remains red on 154 older findings, including test fixtures, source hashes and historical browser profiles. The scan from published 0.5.0 through this integration found zero new leaks. This is not a claim that the historical incident or the full enterprise release checklist is closed.
- The standalone Host does not synchronize existing Desktop chats. Public self-service relay enrollment and physical mobile delivery remain unfinished. macOS is not a published Desktop target. Offline/open clients cannot be forced onto a new binary by publishing the feed.

## Release workflow corrections

- The original Agent work was outside the published Git commit; include both tracked changes and previously untracked source files before making a release candidate.
- Never commit downloaded release sets. Old 0.5.0 artifacts caused the 0.5.1 aggregate gate to see six metadata files instead of three.
- Gate Unix-only test imports as well as their test functions; Clippy on Windows caught imports that Linux accepted.
- EAS needs generated transport/terminal assets. `.easignore` restricts the archive to `mobile/`, and the pre-upload hook rebuilds runtime assets. Verify the actual archive contents, not only the ignore patterns.
- Railway still displays the old Vibeza repository name, which GitHub confirms redirects to Vibyra. The alias is not evidence of a different repository.
