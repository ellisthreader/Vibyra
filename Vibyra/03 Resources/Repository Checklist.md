# Repository Checklist

## System Links

- [[03 Resources/Resources|Resources]]
- [[01 Projects/Projects|Projects]]
- [[02 Areas/Project Maintenance|Project Maintenance]]
- [[02 Areas/Portfolio and Career|Portfolio and Career]]

- Clear purpose and screenshots in `README.md`
- Reproducible setup and run commands
- Focused test or validation command
- Correct `.gitignore`
- No secrets, generated dependencies, or local caches tracked
- Repository URL recorded in the project home note
- Portfolio entry updated when public-facing work changes
